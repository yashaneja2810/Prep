# GamutX LMS

GamutX LMS is a comprehensive Learning Management System designed specifically for VFX and Digital Media education. The platform offers courses, community features, and resources for aspiring VFX software developers.

![GamutX LMS](public/gamutx-screenshot.png)

## Features

- **Course Catalog**: Access specialized courses in VFX Software Development (Foundations and Advanced)
- **Interactive Dashboard**: Track your learning progress and manage enrolled courses
- **VFX Resources**: Industry glossary, technical resources, and learning materials
- **Community**: Forum, meetups, and networking opportunities
- **Badges & Achievements**: Earn badges as you complete courses and milestones
- **Job Board**: Browse VFX industry job opportunities
- **Events Calendar**: Stay updated with industry events and webinars
- **Personalized Learning Path**: Custom learning recommendations based on your goals

## Tech Stack

- **Frontend**: Next.js 15.x with React 19, TypeScript
- **Styling**: Tailwind CSS with shadcn/ui components
- **Animations**: Framer Motion
- **UI Components**: Radix UI for accessible components
- **Forms**: React Hook Form with Zod validation
- **State Management**: React hooks and context APIs

## Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/gx-tools/gx-lms.git
   cd gx-lms
   ```

2. Install the dependencies:
   ```bash
   pnpm install
   # or
   npm install
   ```

3. Run the development server:
   ```bash
   pnpm dev
   # or
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

Troubleshoot
```
npm install --legacy-peer-deps
npm react --version
```
